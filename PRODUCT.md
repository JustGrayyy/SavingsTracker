\# Product



\## Vision



Build an application whose UI quality is indistinguishable from a premium software product.



The benchmark for quality is https://impeccable.style/.



The goal is not to copy copyrighted assets or layouts verbatim, but to reproduce the same level of craftsmanship, polish, hierarchy, spacing, typography, interaction design, and perceived quality.



Every screen should feel intentionally designed rather than AI-generated.



\---



\## Design Philosophy



Every element should have a reason to exist.



Prefer simplicity over decoration.



Reduce visual noise.



Whitespace is a feature.



Typography carries the hierarchy.



Motion communicates state.



Everything should feel expensive.



\---



\## User Experience Goals



The interface should feel:



\- premium

\- calm

\- modern

\- editorial

\- spacious

\- fast

\- responsive

\- deliberate



Never feel:



\- cluttered

\- playful

\- toy-like

\- startup-template

\- bootstrap-ish

\- material-ui default

\- generated by AI



\---



\## Design Priorities



Priority order:



1\. Typography

2\. Spacing

3\. Alignment

4\. Layout hierarchy

5\. Motion

6\. Color

7\. Components

8\. Icons



Never sacrifice spacing for fitting more content.



\---



\## Engineering Rules



Maintain visual consistency across every page.



Do not introduce new component styles unless necessary.



Reuse design tokens.



Preserve rhythm.



Avoid one-off styling.



Every component must belong to the same design language.



\---



\## Quality Standard



Before considering a feature complete:



\- spacing is consistent

\- typography hierarchy is correct

\- animations feel natural

\- components align perfectly

\- responsiveness is polished

\- accessibility is maintained

\- visual clutter removed



If something looks "AI generated", redesign it.



The benchmark is impeccable.style.
